## 構成

1. 背景・目的：2025年のコントローラー手動操作から、2026年の視覚に基づく自動搬送へ
2. システム構成：画像取得→位置・姿勢推定→軌道計画→実行
3. 手法：2枚のマーカーの同時観測と、取付オフセットを含む相対座標変換
4. 実装：自動ピッキングと搬送シーケンス
5. 今後の改良：VLAによる多様な物体の認識・行動計画

利用者の指示により、予備評価・比較グラフ・改善率は掲載しない。開発済みの機能と今後の検証課題を分けて記載。2025年の手動操作は本リポジトリREADMEに記録されたPS4コントローラー遠隔操作実装に基づく。2026年の方式は開始指示後のシーケンス自動実行で、無人で継続動作するとの主張はしない。

## 形式・編集

A4縦・1ページ。演題番号・氏名・所属は記入欄なので提出前に差し替える。特定学会の指定テンプレートではないため、実際の提出規定があればそれに合わせる。

本文・構成図・フロー図・年次比較はPowerPointで編集可能。最新版では数式を掲載せず、座標変換と搬送動作を図と文章で説明し，誤差補正の説明は掲載しない。第5節には「VLAを用いてより多様な物体を認識し行動計画を行う。」と記載。VLAは今後の改良方針であり、現在実装済みの機能ではない。

推奨フォントはNoto Sans CJK JP。日本語フォントがないPCでは置き換わる場合があるので、印刷にはPDFを推奨。PowerPointアプリ上での最終レンダリングは未確認。A4寸法・1スライド・XML構造と配置範囲を確認し、PDFプレビューで文字・余白を目視確認した。

## 再生成

`scripts/create_research_poster.py`。依存はpython-pptx、reportlab、Pillow、lxml。作成時は生成用ライブラリを `/tmp/so101_poster_deps` に取得し、システムやロボット制御環境の依存は変更していない。日本語PDFフォントはDroidSansFallbackFullを使用。

## 最新のデザイン

臙脂色（#82002D）と淡い同系色を基調とした独自デザイン．大学のロゴや公式テンプレートは使用していない．コントローラー，カメラ，モニター，ロボットアーム，物体搬送の模式イラストを追加．本文の句読点は「，」「．」に統一．一般向け展示ポスターは変更していない．
